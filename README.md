#  AgentDebate

A multi-agent application that runs structured debates between two distinct language models (LLMs) and uses an impartial LLM judge to evaluate arguments and declare a winner.

## Overview
- **Debater A (Pro/Affirmative):** Defends a given stance or topic.
- **Debater B (Con/Negative):** Counters with opposing arguments.
- **Judge LLM (Impartial):** Evaluates logical reasoning, clarity, and rebuttal strength across debate rounds.
